# Smart Student Performance Analyzer 

A Python-based student performance analysis project that evaluates students' marks and generates detailed performance reports.

## Features

* Takes marks for Physics, Chemistry, Maths, English, and Hindi
* Calculates total marks and percentage
* Assigns grades from A+ to F
* Determines PASS/FAIL status
* Identifies strongest and weakest subjects
* Handles multiple subjects with the same highest/lowest marks
* Provides personalized performance recommendations
* Calculates class average percentage
* Counts passed and failed students
* Identifies the class topper(s)

## Concepts Used

* Python variables and data types
* User input and output
* `if`, `elif`, and `else`
* `for` loops
* Lists
* String operations
* Comparison operators
* Basic data analysis

## Example

The program generates an individual report containing:

* Student name
* Subject-wise marks
* Total marks
* Percentage
* Grade
* Pass/Fail result
* Strongest and weakest subjects
* Performance recommendations

After all students are processed, it displays a class summary with the class average, pass/fail count, and topper(s).
